    Prelude: universe polymorphic basic types #

    Parsers in Type u return results in Type u, so combinators that would return Unit, Bool or Nat return Unitᵤ, Boolᵤ or Natᵤ instead. These coerce to Bool and Nat, and their Repr instances print the same as Bool and Nat.
