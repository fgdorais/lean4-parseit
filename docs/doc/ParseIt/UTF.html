    UTF-8, UTF-16 and UTF-32 inputs #

    Experimental. This module's API may change in any release.

    Parsers over the characters of UTF-8, UTF-16 and UTF-32 input, using the decoding iterators of UnicodeFormat. Positions are those of the encoded input: byte offsets for UTF-8, and code unit indices for UTF-16 and UTF-32.

    A strict decoding iterator ends at the first ill-formed input, so a parser sees the end of the input there. Parser.parseDecoded and the parseUTF8, parseUTF16 and parseUTF32 runners report the ill-formed input as an error when the parser stops where decoding stopped, or fails there. A parser that goes on after ill-formed input instead can consume it with UTF.illFormed.

          ParserT ε (Unicode.DecodeIterator δ ι) Char m Unicode.DecodeError.Kind

          illFormed consumes the ill-formed input where a strict decoding iterator stopped, and returns its kind, so that a parser can report it and go on after it. Fails, consuming nothing, at well-formed input and at the end of the input. On a lossy decoding iterator, it consumes ill-formed input before it is replaced with U+FFFD.

            def ParseIt.Parser.parseDecoded {ε δ ι τ α : Type} [Unicode.Decoder δ τ Char] [Std.Iterator ι Id τ] [Std.Iterators.Finite ι Id] [Error ε (Unicode.DecodeIterator δ ι) Char] (p : Parser ε (Unicode.DecodeIterator δ ι) Char α) (it : Std.Iter Char) :
            Except ε α

            p.parseDecoded it runs p on the characters of the decoding iterator it. When it is strict and stops at ill-formed input, and p succeeds and stops there, that input is reported as an error at its position. When p fails, its error is kept, and a message about the first ill-formed input of it is added to it, which Error.Simple records and Error.Basic discards. That message is about the first ill-formed input even when p consumed it with UTF.illFormed and failed later.
