    Scalar array inputs #

    Parsers over the elements of the arrays of lean4-scalar-arrays: HasPos instances for their slice iterators, and a runner named after each array type, such as parseUInt8Array for UInt8Array. A runner also takes a slice of the array; an array coerces to a slice of all its elements. Positions are indices in the underlying array, not in the slice. Parser.parseSlice remains the runner for String.Slice.

    These arrays are named UInt8Array and Float64Array because core has ByteArray and FloatArray. parseFloatArray uses the same iterator as parseFloat64Array, so a parser for one runs on the other. parseByteArray uses ByteIterator instead, so only a parser that is polymorphic in the iterator runs on both it and parseUInt8Array.
