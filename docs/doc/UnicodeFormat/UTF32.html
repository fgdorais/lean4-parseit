    UTF-32 #

    Each code point is a single code unit. A code unit that is a surrogate in D800–DFFF or above 10FFFF is ill-formed.

    Decoding uses the decoder of UTF32.decodeIter. decode reports the position of the first ill-formed code unit, as an index in the slice.
