    UTF-16 iterators #

    UTF16.decodeIter reads characters from UTF-16 code units, and UTF16.encodeIter writes them back. An unpaired surrogate is ill-formed. A high surrogate reads its low surrogate by looking ahead; when there is none, only the high surrogate is ill-formed, and lossy decoding goes on from the next code unit.

          @[inline]
          def Unicode.UTF16.decodeIter {ι : Type} (it : Std.Iter UInt16) :
          Std.Iter Char

          Decodes the UTF-16 code units of it, stopping at the first unpaired surrogate.

          A for loop or fold over the result ends at ill-formed input just as at the end of the input. To tell them apart, fold with decodeFold, which also returns the iterator where decoding stopped, and check decodeError? there, find the first ill-formed input ahead with decodeFailure?, or decode with decodeIterLossy instead.
