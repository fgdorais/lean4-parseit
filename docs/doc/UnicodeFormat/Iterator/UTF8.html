    UTF-8 iterators #

    UTF8.decodeIter reads characters from UTF-8 bytes, and UTF8.encodeIter writes them back. The well-formed byte sequences are those of the Unicode Standard, Table 3-7. Ill-formed input is a maximal subpart: the longest prefix of a well-formed sequence that it starts with, or a single byte if none. Lossy decoding replaces each maximal subpart with U+FFFD, following the recommended practice of the Standard, Section 3.9.

    UTF8.skipSignature skips the bytes EF BB BF that sometimes start UTF-8 data.

          @[inline]
          def Unicode.UTF8.decodeIter {ι : Type} (it : Std.Iter UInt8) :
          Std.Iter Char

          Decodes the UTF-8 bytes of it, stopping at the first ill-formed byte sequence.

          A for loop or fold over the result ends at ill-formed input just as at the end of the input. To tell them apart, fold with decodeFold, which also returns the iterator where decoding stopped, and check decodeError? there, find the first ill-formed input ahead with decodeFailure?, or decode with decodeIterLossy instead.
