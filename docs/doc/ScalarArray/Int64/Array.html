                  Linearity #

                  source
                  @[never_extract, extern lean_sarray_mark_linear]
                  def ScalarArray.Int64Array.markLinear (a : Int64Array) :
                  Int64Array

                  Marks a as linear, a debugging aid: if a marked array is ever copied because it is shared when it needs to be exclusive, as before an in-place write, the runtime panics. The mark goes on an exclusive array, so if a is shared it is copied first and the copy is marked. Logically this is the identity.

                  Equations
                  • a.markLinear = a
