    In-place writes on Int64Array #

    Writes through slices, and folds that write each element back in place.

    Writes through slices #

    source
    @[inline]
    def ScalarArray.Int64Array.Slice.set (s : Int64Array.Slice) (i : Nat) (v : Int64) (h : i < Std.Slice.size s := by get_elem_tactic) :
    Int64Array.Slice

    Replaces the element at index i of the slice, counted from the start of the slice, in the underlying array. The array is updated in place when neither it nor the slice is shared, so a slice taken from an array that is no longer used writes into that array. s.array gives back the whole array afterwards.

                  Replaces each element of the slice while threading an accumulator, in place like set: for each k < s.size, from 0 up, the element x at index k of the slice becomes the first component of f k hk x b, whose second component is the next accumulator. Returns the new slice and the last accumulator.

                  The array is made exclusive once, before the loop, which then stores without checks, where each set checks at every write. f only sees the elements, never the array, which is what makes skipping the checks safe. The proof hk : k.toNat < s.size lets f read other arrays with uget.

                              Writes the window of len elements at rs from the windows at xs and ys of the same array, in place, threading an accumulator: for each j < len, from 0 up, it reads x := a[xs + j] and y := a[ys + j] from the current array, then stores the first component of f j hj x y b at rs + j, and the second component is the next accumulator. Returns the new array and the last accumulator.

                              Each step reads after the writes of the earlier steps, so overlapping windows are well defined: with rs = xs + 1, for example, step j reads what step j - 1 wrote. Reading the windows through f rather than through another reference to a keeps a exclusive, which a second reference would not, and then the first write would copy the whole array.

                              The array is made exclusive once, before the loop, which then reads and stores without checks.
