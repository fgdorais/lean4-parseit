    Arrays of USize: basics #

    The type, its model, and the operations compiled to the runtime: reads, writes, push, capacity, append and copySlice.

    source
    def ScalarArray.USizeArray :
    Type

    Arrays of USize values, stored unboxed in a scalar array, one machine word per element.

    The logical model is an Array USize: USizeArray.mk and USizeArray.toArray convert between the two. cases and induction split a USizeArray as mk a.
