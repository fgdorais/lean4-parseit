    The runtime representation of scalar arrays #

    ScalarArray.Raw exposes the Lean runtime's scalar array objects (lean_sarray_object), the representation behind ByteArray and FloatArray. A scalar array is a header recording the element size, the size and the capacity, followed by the elements stored unboxed.

    This module binds the runtime functions on that header: allocation, size and capacity queries, copying, resizing and copies of raw bytes. The typed array modules use it as their runtime representation through import all ScalarArray.Internal, and reach it with unsafeCast. Their own externs are only those that are part of their API, such as size, decEq and markLinear, and the reads and writes uget and setUnsafe, whose C names the element type.

    Only what the typed modules' inlined code calls is public: the type, size, capacity, resizeUnsafe and ensureExclusive. Inlined code can only use declarations of publicly imported modules, so the typed modules import this one publicly, and these are visible wherever ScalarArray is imported. They are not part of the API. The rest is private.
