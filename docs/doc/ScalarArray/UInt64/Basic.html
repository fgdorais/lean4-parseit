    Arrays of UInt64: basics #

    The type, its model, and the operations compiled to the runtime: reads, writes, push, capacity, append and copySlice.

    source
    def ScalarArray.UInt64Array :
    Type

    Arrays of UInt64 values, stored unboxed in a scalar array, 8 bytes per element.

    The logical model is an Array UInt64: UInt64Array.mk and UInt64Array.toArray convert between the two. cases and induction split a UInt64Array as mk a.
