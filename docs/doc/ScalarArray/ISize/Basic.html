    Arrays of ISize: basics #

    The type, its model, and the operations compiled to the runtime: reads, writes, push, capacity, append and copySlice.

    source
    def ScalarArray.ISizeArray :
    Type

    Arrays of ISize values, stored unboxed in a scalar array, one machine word per element.

    The logical model is an Array ISize: ISizeArray.mk and ISizeArray.toArray convert between the two. cases and induction split a ISizeArray as mk a.
