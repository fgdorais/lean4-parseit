    Loops with several variables #

    The loops in continuation-passing style of the arrays' tail programs with 2 to 8 variables, XArray.InPlace.Tail.forIn2, … and XArray.InPlace.Tail.forInRev2, …, over any state σ: each array's loops wrap these, with its own state. They are for internal use: the arrays' loops are the API. Each variable is an argument of the loop, so that scalars stay unboxed.

    This module is generated by scripts/generate.py, from scripts/loop_template.py.
