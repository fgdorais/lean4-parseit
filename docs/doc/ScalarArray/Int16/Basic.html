    Arrays of Int16: basics #

    The type, its model, and the operations compiled to the runtime: reads, writes, push, capacity, append and copySlice.

    source
    def ScalarArray.Int16Array :
    Type

    Arrays of Int16 values, stored unboxed in a scalar array, 2 bytes per element.

    The logical model is an Array Int16: Int16Array.mk and Int16Array.toArray convert between the two. cases and induction split a Int16Array as mk a.

                  @[instance_reducible, implemented_by ScalarArray.Int16Array.Internal.decSizeLtImpl, instance 10000]
                  instance ScalarArray.Int16Array.decSizeLt (a : Int16Array) :
                  Decidable (a.size < USize.size)

                  Decides a.size < USize.size, which holds for every array in memory, as for usize. The safe loops index with USize, so their csimp proofs test the bound, with a fallback for the other case. At runtime this instance is isTrue without a test, so the compiler removes the test and the fallback, which would otherwise cost a Nat comparison and, when the fallback calls a fold, a closure for its function. This is the one unchecked fact behind those proofs.
